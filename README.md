# Rally Pong

A two-player browser Pong game with rally tracking, a long-rally bonus, and a win-by-two match rule.

## Play

Open `index.html` in a modern browser. No build step or dependencies are required. You can also serve the repository with any static file server.

- **Player 1 (left paddle):** W / S
- **Player 2 (right paddle):** Up / Down arrow keys
- **Start / continue:** click the on-screen button, or press Space / Enter

Each point is worth 1. If a rally reaches 10 paddle hits, the player who wins that rally receives 2 points. The first player to reach at least 11 points and lead by 2 wins.
